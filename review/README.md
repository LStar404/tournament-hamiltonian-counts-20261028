# 复核记录的范围

本目录收录论文第四版已有的复核记录。`研究定位说明.txt` 区分本文的结论与所引用文献；`复核说明.txt` 汇总数学、文字和排版检查，并明确有限检验及历史形式化工作没有覆盖的部分。

`math_review.txt` 是多轮审阅的累计记录，包含当时的章节号、行号和修订建议。它是一份历史工作记录，其中提及的旧版稿件和中间脚本未打包。应以当前论文中的陈述和编号为准。

`proof_preservation.json` 记录显示公式的顺序保留；`structural_audit.json` 记录中英文公式对应和结构检查；`added_identities.json` 记录新增恒等式的有限验证。它们分别回答编辑一致性和有限实例问题，不能被解释为已经证明所有数学结论正确。

`pdf_review.json`、`final_review.json` 对应第四版原排版的 PDF 快照。之后更换字体所得 PDF 的哈希和分页可能不同，最终交付应使用随后补入的最新排版记录与文件清单核对。旧记录保留其原有哈希，避免把一次检查移用于未经检查的文件。

为去除本机目录信息，`pdf_review.json` 中的联系表绝对路径已在此复制件内改为“稿件名/联系表文件名”的历史标识。这些联系表图片未随仓库收录，记录里的标识也不是当前文件链接。其余复核内容保留。

`source_review.md` 汇总本轮最终采用的来源对应及明确修正的文献编号，供阅读正文时查找。
