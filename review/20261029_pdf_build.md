## 字体与实际编译副本

仓库 TeX 保留原排版意图。实际云端构建使用单独工作副本，只有前言作以下替代；从 `\begin{document}` 起的字节与最终 TeX 完全相同，哈希列于构建清单。

| 原字体 | 本次替代 | 注意事项 |
| --- | --- | --- |
| Times New Roman | Liberation Serif | 不是同一字体，字形及字距不保证完全相同 |
| Arial | Liberation Sans | 不是同一字体 |
| Consolas | DejaVu Sans Mono，仍按0.82缩放 | 非度量兼容替代 |
| Noto Serif SC Regular | 系统 Noto Serif CJK SC Regular | 不同字体版本/字节；明确选择 SC face |
| Noto Sans SC SemiBold 600 | 系统 Noto Sans CJK SC Bold 700 | 比原字重更重 |

Noto CJK 的 SC face 从系统字体集合中提取，未改轮廓。共享 CFF 内部 FontName 可能显示 jp，但所选 name table 和 cmap 为 SC。全部 PDF 字体均已嵌入。不能把本次结果称为原字体逐字节复刻，分页和字形以这次全页审阅结果为准。

指南原文使用 `LTcaptype=none` 表示无编号长表；本次 longtable 4.23 要求该值为空。构建脚本只在工作前言加入局部兼容钩子，把 none 映射为空，并递增内部 `LT@tables` 使两张无编号表使用各自的辅助记录；不更改表格正文或可见编号。三遍后表宽收敛。

## 离线复现

```bash
python3 tools/compile_portable_pdfs.py --root . --output build/portable-pdf
```

脚本不安装或下载任何依赖、不改原 TeX、不启用 shell escape。需预装 XeLaTeX、xeCJK、相应 longtable、fontconfig、Python fontTools，以及上述替代字体。输出工作副本、字体来源哈希、正文一致性哈希、编译日志和 PDF；按引用与表宽收敛自动运行2至5遍。新生成 PDF 的时间戳和子集字体标识可能不同，不保证 PDF 文件哈希跨运行恒定。

本次验证环境为 XeTeX 0.999996 / TeX Live 2025-dev Debian，LaTeX 2024-11-01 patch 2，longtable 4.23。xeCJK 3.9.1 和 ctexhook 从官方 CTeX `9599832f18486e503eeeed23130210c0c451d8f1` 的源码局部提取，未改系统安装。源文件的其余宏包均来自现有 TeX 安装。独立可复现脚本已在第05份短文上完整运行；其页面像素与本次交付 PDF 一致。
