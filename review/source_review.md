# 结果来源核对

本表记录本稿实际调用的主要结果。文献编号以合稿为准，详细推导与适用条件见正文。表中“本文计算”表示稿件所给的推导，不表示已经完成覆盖全部相关文献的优先权检索。

| 对象 | 来源与使用范围 |
|---|---|
| 路径与圈极值的首项常数 $L$ | [Divoux–Wang](https://arxiv.org/html/2610.23755v1)，定理 1.4 及其圈数结果；圆环与偶阶删点构造见第 9—10 节 |
| 全局路径归一化误差 $O(n^{-1})$ | 合稿定理 1.1；需要本文在永久式、删点、缩放和求和中的一致估计 |
| 永久式的行列式近似与 $O(n^{-1})$ 误差阶 | [McCullagh](https://arxiv.org/abs/1205.5723) 已有该阶误差；Divoux–Wang 命题 3.1 陈述为非负双随机矩阵上一致的 $1+o(1)$，正文另写保留定量余项后的细化 |
| 高斯矩及算术—几何平均工具 | [Han–Niles-Weed v2](https://arxiv.org/html/2408.09341v2)，引理 4.3—4.4；不是路径计数渐近式的来源 |
| 原角 Hessian | 本文从 [Wormald](https://arxiv.org/html/2610.16245v1) 的隐式角函数计算完整矩阵、正定性及行列式；模型计数仍调用其定理 1、4、5 |
| 固定正则基图的模型常数 | Divoux–Wang 命题 5.1 的加权矩阵代入可直接给出；正则内部块乘子和路径转换仍依赖 Wormald |
| 谱半径界与相位排序证明 | [Deng–Li–Shader–So 作者版本](https://cfc.nankai.edu.cn/_upload/article/files/09/3a/890a6a5c4660ae2350ac183d2dfa/cb663bb2-4ff4-476f-8047-50514a7780a5.pdf)，Theorem 3.1。先前的 Theorem 7.1/Corollary 7.2 编号已更正 |
| 传递矩阵特征多项式 | 同上 Theorem 2.1；该引用已核实保留 |
| 矩阵幂比较及等号 | [Fang–Huang v1](https://arxiv.org/html/2608.06238v1#S3)，Corollary 3.4 及相关等号分析；Divoux–Wang 命题 7.1、引理 9.1 用于谱比值上界与圆环取等 |
| 固定基图的期望唯一极值 | 合稿将上述已有计数与谱比较同零行和条件结合，再估计非正则基图，使用固定阶图类有限性得出推论 |
| 圆环闭式与极限 | 承接 Divoux–Wang、Wormald；严格单调性由 Fang–Huang 显式频率及已有正系数展开进一步推出，高阶展开是闭式后的计算 |

技术补充中的 $C_*>L$ 上界保留详细推导，但它在充分大阶数时已由已有的首项结果覆盖。本文不将其列为独立的主要新结果。
