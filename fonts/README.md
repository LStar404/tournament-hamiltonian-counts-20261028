# 配套中文字体

正文使用 Noto Serif SC 的 400 字重静态实例，标题和中文粗体使用 Noto Sans SC 的 600 字重静态实例。
它们由本机安装的官方变量字体使用 fontTools 固定字重生成，保留原有字体名称与版权信息；不依赖系统默认的细体实例。

- [Noto Serif SC 来源与许可](https://github.com/google/fonts/tree/main/ofl/notoserifsc)
- [Noto Sans SC 来源与许可](https://github.com/google/fonts/tree/main/ofl/notosanssc)

各字体遵循随附的 SIL Open Font License 1.1。字体许可不改变论文及其他材料各自的权利归属。
TeX 通过相对文件路径加载字体，不需要安装到操作系统。英文字体仍使用 Times New Roman、Arial、Consolas。
